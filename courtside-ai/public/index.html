CourtSide AI

Voice-scored court tablets and one organizer desk, synced live. Built for the multi-court club tournament: singles, doubles, No-Ad, Fast4, tiebreaks, changeover timers, and a sponsor loop that pays for the tablets.

How the pieces talk

Run npm start and every page connects to the WebSocket hub on this server. Open the pages without a server and they fall back to a BroadcastChannel between tabs of the same browser, with the organizer tab acting as the hub. Either way a court tablet keeps scoring while disconnected: updates queue on the device and replay when the link returns.

On a court tablet, say the score before serving, server first — “30-15”, “deuce”, “ad in”, “game” — or “fault”, “let”, “correction”, “umpire”. The tablet only accepts a call that is one point away from the score it already knows, which is what keeps the next court’s calls out.
